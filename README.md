## 這個試用版能做什麼

- 左邊表格、右邊 A4 預覽，打什麼就變什麼
- 每一列自己算：計算式欄只吃 `× ÷ + - ^ ( )`，結果自動出現
- 算式與結果印在同一列，交出去看得到依據
- 「Σ 小計」自動加總上方明細；插列、刪列都像 Excel
- **沒有「總計」**：平方公尺與公斤不能相加，不提供假的總數
- 單位自由輸入（塊、袋、樘、組、才）
- 五個計算器：鋼筋、磚井（集水井）、管路、加勁格網、線性內插
- 參數不足或超出表格範圍時直接顯示算不出來（不猜值）
- 常數內建：π = 3.142、鬆方率 1.3、管路損耗 1.1、植草 1.12，每步四捨五入至小數 3 位
- A4 預覽即時、資料不足自動補空白列、框線貼齊頁尾
- 資料自動存在本機瀏覽器

## 試用版限制
